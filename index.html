প্রেসক্রিপশন থেকে বিক্রি করার সময় কতটা মিলি লাগবে সেই হিসাব থেকে ঠিক কয়টা বোতল দরকার তা বের করতে এটা ব্যবহার হয়। (ড্রপের ক্ষেত্রে ১ মিলি = ২০ ফোঁটা ধরে হিসাব হয়)

প্যাকের ভেতরে থাকা ট্যাবলেট/ক্যাপসুলের মোট সংখ্যা লিখুন (এটা ওষুধভেদে ভিন্ন হয় — কোনোটায় ১০টা, কোনোটায় ২০টা, কোনোটায় ৩০টা থাকে)। প্রেসক্রিপশনে যে ডোজ লেখা হবে সেই অনুযায়ী বিক্রির সময় এই সংখ্যা দিয়ে হিসাব করে ক'টা কৌটা লাগবে বের হবে।

☁ ক্লাউড ব্যাকআপ সংযোগ

    

      এটি একবার করলেই আপনার সব বিক্রয়, স্টক, কাস্টমার তথ্য ইন্টারনেটে (Firebase) নিরাপদে জমা থাকবে। নতুন ফোনে এই অ্যাপ খুলে নিচের একই তথ্য দিয়ে সংযোগ করলে সব ডাটা ফিরে পাবেন। সম্পূর্ণ ফ্রি, কোনো কোডিং লাগবে না — মাত্র ৫ মিনিট।
    

    

    ধাপ ১: Firebase প্রজেক্ট তৈরি করুন
    

      ১) মোবাইলে console.firebase.google.com এ যান, Google অ্যাকাউন্ট দিয়ে লগইন করুন

      ২) "Add project" চাপুন, নাম দিন (যেমন: nrisingha-medical), Continue চাপতে থাকুন

      ৩) বাম মেনু থেকে Build → Firestore Database এ যান → Create database → "Start in test mode" বেছে নিন → পছন্দের লোকেশন দিয়ে Enable করুন

      ৪) প্রজেক্ট সেটিংস (⚙ আইকন) → নিচে স্ক্রল করে "Your apps" → ওয়েব আইকন </> চাপুন → একটা নাম দিয়ে Register করুন

      ৫) যে firebaseConfig কোড দেখাবে, তার পুরোটা কপি করে নিচে পেস্ট করুন (শুধু { ... } অংশটুকু)
    

    

    
    
    
    
    
    
নতুন ফোনে শুধু এই একই "দোকানের কোড" ও Config দিয়ে আবার সংযোগ করলেই ডাটা ফিরে আসবে।
